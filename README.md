# 하민이의 점프 게임

HTML5 Canvas, CSS, Vanilla JavaScript ES Module로 만든 세로형 자동 점프 게임입니다. 회원가입 후 높이와 보너스에 따라 점수가 오르며 12종의 동물로 성장합니다. 계정별 기록·코인·업그레이드·아이템은 Vercel Functions와 Neon Postgres를 통해 모든 기기에서 공유됩니다.

## 계정, 기록과 코인

- 첫 화면에서 로그인과 회원가입을 동시에 선택할 수 있습니다.
- 비밀번호는 서버에서 scrypt로 해시되며 원문으로 저장되지 않습니다.
- 로그인 세션은 HttpOnly 쿠키로 유지됩니다.
- 같은 계정으로 로그인하면 다른 브라우저와 기기에서도 기록·코인·업그레이드·아이템이 동일하게 표시됩니다.
- 기존 브라우저 전용 계정 데이터는 서버 계정 시스템 적용 시 한 번 초기화됩니다.
- 게임에서 얻은 점수가 코인으로 정산되며, 코인 강화 단계에 따라 최대 50% 보너스를 받습니다.
- 로그인 후 화면 상단의 `기록`, `지갑`, `상점` 버튼을 언제든 사용할 수 있습니다.

## 코인 스토어

영구 강화:

- 점프 강화: 단계마다 점프 높이 4% 증가
- 이동 강화: 단계마다 좌우 이동 속도 5% 증가
- 코인 보너스: 단계마다 코인 획득량 10% 증가
- 출발 보호막: 매 게임 보호막을 장착하고 시작

한 게임용 아이템:

- 슈퍼 로켓: 즉시 강하게 상승
- 천사 날개: 6초 동안 지속 상승
- 보호막: 추락을 한 번 방어
- 황금 깃털: 6초 동안 낙하 속도 감소

구매한 소모품은 게임 화면 오른쪽 아래의 아이템 버튼으로 사용하며 한 번 사용할 때 1개가 차감됩니다.

## 실행

프로젝트 폴더에서 아래 명령을 실행한 뒤 `http://localhost:8000`을 엽니다.

```bash
python -m http.server 8000
```

파일을 직접 더블클릭하면 ES Module 보안 정책 때문에 실행되지 않을 수 있습니다.

계정 API까지 로컬에서 실행하려면 Vercel CLI와 `HAMIN_DB_DATABASE_URL` 환경 변수가 필요합니다. 운영 환경에서는 Vercel Marketplace Database가 프로젝트에 연결되어 환경 변수를 자동 제공합니다.

## 폴더 구조

- `index.html`, `styles.css`: 화면과 반응형 레이아웃
- `src/Game.js`: 게임 상태와 메인 루프
- `src/entities/`: 플레이어, 플랫폼, 아이템, 파티클
- `src/systems/`: 물리, 충돌, 카메라, 레벨, 플랫폼 생성
- `src/ui/`: HUD, 시작, 게임 오버 화면
- `assets/raw/animal-sprite-sheet.png`: 제공된 원본 시트
- `assets/sprites/level1`~`level8`: 추출된 상태별 PNG
- `scripts/extract_sprites.py`: 스프라이트 추출 도구

## 스프라이트 다시 추출

```bash
pip install pillow
python scripts/extract_sprites.py
```

시트의 행은 Lv.1~Lv.8, 열은 `idle`, `jump`, `rise`, `fall`, `landing`, `crouch` 순서입니다. 시트 여백이 달라지면 스크립트 상단의 `CROP_*` 값을 수정하세요. 가장자리에 연결된 `RGB > 242` 배경만 투명화하므로 동물 내부의 흰색은 보존됩니다.

## 조작법

- `←/A`, `→/D`: 좌우 이동
- `Space`: 시작 또는 재시작
- `P`: 일시정지
- `M`: 음소거
- 모바일: 화면 왼쪽/오른쪽을 누르고 떼기

좌우 화면 밖으로 나가면 반대편에서 이어집니다. 플랫폼은 하강 중 위에서 닿을 때만 착지합니다.

## 실시간 레이스

시작 화면에서 `친구와 실시간 레이스`를 선택합니다.

1. 한 명이 방을 만들고 표시된 6자리 코드를 공유합니다.
2. 친구들이 코드를 입력해 참가합니다(방장 포함 최대 4명).
3. 방장이 초급·중급·고급 중 레이스 난이도를 선택합니다.
4. 방장이 시작하면 모든 참가자가 같은 난이도·발판 배치·바람 방향으로 동시에 출발합니다.
5. 상대 캐릭터는 반투명한 고스트로 함께 표시되며, 우측 상단에서 상대 점수를 확인할 수 있습니다.
6. 탈락하면 최종 순위를 봅니다.

카메라나 마이크는 사용하지 않으며 게임 상태만 P2P 데이터 연결로 교환합니다. 방장의 브라우저가 방 역할을 하므로 레이스가 끝날 때까지 방장 탭을 닫지 마세요. 회사·학교 네트워크나 엄격한 방화벽 환경에서는 WebRTC 연결이 제한될 수 있습니다.

## 성장 단계와 캐릭터 도감

시작 화면의 `캐릭터 도감`에서 전체 성장 조건을 볼 수 있습니다.

아기 토끼(0), 토끼(500), 점프 토끼(1,200), 다람쥐(2,200), 여우(3,500), 사자(5,200), 호랑이(7,500), 판다(10,500), 도마뱀(14,000), 사슴벌레(18,000), 장수풍뎅이(22,500), 양(28,000).

성장 시 현재 점수·위치·플랫폼을 유지하면서 이동 속도와 점프력이 증가합니다. 레벨 3부터 이동 플랫폼, 레벨 4부터 부서지는 플랫폼과 날개, 레벨 6부터 사라지는 플랫폼과 보호막이 등장합니다.

## 아이템

- 별: 100점
- 스프링: 1.6배 점프
- 날개: 3초간 상승
- 보호막: 한 번의 추락을 막고 가까운 플랫폼으로 복귀
- 보석: 250점
- 깃털: 3.5초간 천천히 낙하

## 레벨별 신규 요소

- Lv.3: 좌우 이동 발판
- Lv.4: 부서지는 발판
- Lv.5: 캐릭터를 옆으로 보내는 컨베이어
- Lv.6: 나타났다 사라지는 발판
- Lv.7: 한 번 밟으면 흩어지는 구름 발판과 보석
- Lv.8: 미끄러운 얼음 발판과 깃털
- Lv.9: 폭이 늘었다 줄어드는 맥동 발판
- Lv.10: 1.85배 점프하는 로켓 발판
- Lv.11: 방향이 바뀌는 고공 바람
- Lv.12: 보너스 점수와 점프를 주는 무지개 발판

## 디버그 모드

`http://localhost:8000/?debug=true`로 실행합니다.

- `1`~`9`: 레벨 1~9 강제 변경
- `0`, `-`, `=`: 레벨 10, 11, 12 강제 변경
- `L`: 다음 레벨 점수 부여
- `G`: 중력 켜기/끄기
- `B`: 충돌 박스 표시
- `R`: 재시작

## 이미지 교체

같은 경로에 256×256 투명 PNG를 넣으면 됩니다. 이미지가 없거나 로드에 실패해도 레벨 번호가 표시된 대체 동물이 렌더링됩니다. 오디오 파일 없이 Web Audio로 짧은 효과음을 생성하며, 오디오를 사용할 수 없어도 게임은 계속됩니다.

## 알려진 제한

모바일 진동과 외부 음원은 포함하지 않았습니다. 브라우저 자동 재생 정책에 따라 첫 입력 전에는 소리가 나지 않습니다.
